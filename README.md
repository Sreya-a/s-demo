# AI Micro-Interactions Customizer

A front-end prototype that helps users design and preview responsive, physics-based micro-interactions through a natural-language workflow.

## Live Demo
https://sreya-a.github.io/s-demo/

## Project Structure

```text
ai-micro-interactions-customizer/
├── index.html
├── css/
│   └── styles.css
├── js/
│   └── app.js
├── .nojekyll
├── .gitignore
└── README.md
```

## Main User Flow

Landing Page → Start Designing → Create Animation → AI Suggestions → Live Preview → Export → Settings

## Features

- Natural-language animation prompt workflow
- AI suggestion interface
- Responsive live preview
- Animation settings such as duration and physics
- Export/code preview for CSS, React, Flutter, Figma and Lottie JSON
- GitHub Pages compatible static deployment

## Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- GitHub Pages for deployment
